Virtual Private Network

Creates a secure **encrypted** connection over an untrusted network

Allows users or networks to communicate as if they were connected in a private network

### types
- Remote access VPN
	- Connects and individual to a private network
- Site to Site VPN
	- Connects two networks together

### components
- VPN Client
	- software installed on an end user's device that creates a VPN connection
- VPN gateway/server
	- Authenticates users
	- Establishes encrypted tunnels
	- Routes the traffic between networks

### encryption
- IPsec
	- For site to site VPNs
- SSL/TLS VPN
	- For browser based remote access
- WireGuard
	- Modern VPN protocol for speed and security
- OpenVPN
	- Widely used open source VPN protocol
