Wi-Fi - Wireless fidelity

Allows devices to connect to a network wirelessly by using radio frequency signals instead of physical cables

Primarily operate at these bands:
- 2.4 GHz
- 5 GHz
- 6 GHz

### components
- Wireless Access Point (AP)
	- Provides wireless connectivity to clients
- Wireless client
	- A device that connects to an AP
- SSID (service set identifier)
	- Name of the wireless network that users see when selecting a network

### password protocols
- WEP (Wired equivalent privacy)
	- Old, very old
	- Broken, do not use!
- WPA (Wi-Fi protected access)
	- Improvement of WEP
	- Mostly been replaced
- WPA2
	- Common standard
	- Uses AES encryption
	- Stronger than WEP/WPA
- WAP3
	- Newest standard
	- Stronger encryption
	- Improved auth

### attacks
- [[evil twin]]
- [[rogue access point]]
- [[deauthentication]] attack
- packet capture

### best practices
- Avoid WEP/WPA, use WPA2 or WPA3
- Use strong passwords
- Separate guest networks
- Monitor for rogue APs
- Regularly update firmware
