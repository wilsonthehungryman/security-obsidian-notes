| ------------------- | ---------------------------------------------------------------------------------------------------------- |

| White box/Glass box | Information provided like code, infra, diagrams, creds, etc                                                |
| Grey box            | Limited knowledge like standard user creds, basic diagrams, etc                                            |
| Red box             | Red teaming                                                                                                |
| SOW                 | Document that defines the expectations for a specific business arragement                                  |
| MSA                 | Contract that establishes precedence and guideline for any business documents executed between two parties |
| ROE                 |                                                                                                            |
